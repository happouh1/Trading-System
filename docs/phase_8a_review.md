# Phase 8A review

## Implemented

- Immutable versioned config, cohort, and test-result contracts.
- Exact one-sided cluster-mean sign probabilities without floating randomization.
- Deterministic Holm familywise adjustment with stable identity tie-breaking.
- Input normalization, duplicate rejection, finite-value checks, and explicit zero handling.
- Tests for formulas, permutation invariance, configuration, and authority boundaries.

## Excluded

No database adapter, persistence, parameter selection, efficacy claim, scoring change, alert,
options routing, broker write, or live trading is implemented. Phase 8A is a statistical reference
foundation, not a completed evaluation of real system evidence.

## Exit criteria

- Exact statistical examples pass: satisfied.
- Input permutations produce identical results: satisfied.
- Holm correction uses the complete supplied family: satisfied.
- Production authority remains false: satisfied.
